Shared Streamlit interface for the master thesis project.

- Approach 1: Building Extraction
- Approach 2: Road Extraction

## Safety rule

This UI is an orchestration and presentation layer only.
It must not merge or overwrite the existing `Buildings/` or `Roads/`
backend implementations.

The existing Buildings UI remains available as the Approach 1 rollback
baseline.
